## 0. 结论摘要

1. KS 方程本质是**两股力的竞争**：扩散（μ）把密度抹平，趋化（χ）把密度往化学浓度高处吸。再加上流场（σ）做剪切。3D 里还有一个**正则化尺度 δ** 把 `1/r` 奇异性抹平。
2. 判断"谁主导"不需要看绝对数值，只需比较**三个位移尺度**：剪切 `D_s=σT`、扩散 `D_μ=√(2μT)`、趋化 `D_c=χMT/(4πR₀²)`。当前实验里它们是 **0.3–4.0 : 0.2 : 0.08** —— **这是一个"剪切主导、趋化只是弱扰动"的区间**。
3. 如果把网络输入从一个参数扩到两个，**推荐 (σ, χ)**：在 μ、T、δ、R₀ 固定的前提下，它们恰好独立地控制两个无量纲数 `S=σT/R₀` 与 `C=χT/R₀³`，构成一张真正的二维"剪切 vs 趋化"相图。次选 (σ, μ) 或 (χ, μ)。
4. **不要选 (σ, T)**：T 会同时放大剪切和趋化（`S∝T, C∝T`），二者沿同一条射线走，属于退化方向。

## 1. KS 方程从哪里来

### 1.1 两场形式（DP 文式 (1)）

```
ρ_t = ∇·( μ∇ρ − χρ∇c )           细菌密度 ρ 的演化
ε c_t = Δc − k²c + ρ              化学引诱剂浓度 c 的演化
```

- `ρ(x,t)`：细菌密度（active particles）
- `c(x,t)`：化学引诱剂浓度（chemo-attractant）
- `μ`：细菌随机游走（扩散）系数
- `χ`：**趋化敏感度**（chemo-sensitivity）——细菌沿 `∇c` 上爬的强度
- `ε`：化学场的响应时间。`ε=0` → 化学场瞬时平衡（elliptic）；`ε>0` → parabolic
- `k`：化学物质的降解/耗散率

### 1.2 消去 c：单场非局部方程

取 `ε=k=0`，`c` 满足 Poisson 方程 `−Δc = ρ`，于是 `c = −K ∗ ρ`（K 是 Laplacian 的 Green 函数），代回得：

```
ρ_t = μΔρ + χ∇·( ρ ∇(K∗ρ) )                        （DP 文式 (2)）
```

加流场后（流不可压，`∇·v=0`）：

```
ρ_t + v·∇ρ = μΔρ + χ∇·( ρ ∇(K∗ρ) )                （DP 文式 (3)，TS 文式 (13)）
```

**每一项的物理含义**：

| 项 | 含义 | 效果 |
|---|---|---|
| `μΔρ` | 布朗扩散 | 把密度抹平、扩大支撑 |
| `χ∇·(ρ∇(K∗ρ))` | 趋化：细菌向"自己人"聚集的方向爬 | 收缩、成团、最终可能爆破 |
| `v·∇ρ` | 流场平流 | 剪切、拉伸、混合 |

Green 函数的具体形式由维度决定：

- **2D**：`K = −(1/2π)·ln|x|`（对数核）
- **3D**：`K = 1/(4π|x|)`（牛顿核）
- **4D**：`1/(4π²|x|²)`——TS 文附录 A.1 **没有**用这个，而是把 3D 核直接套在 4 个坐标上，明确标注为"extension"，不是物理自洽的 4D 模型。

### 1.3 粒子系统（真正被数值求解的东西）

宏观方程 (3) 是下面这个相互作用粒子系统在 `J→∞` 时的 McKean–Vlasov 极限（DP 文式 (4)）：

```
dX_j = −(χM/J) Σ_{i≠j} ∇K(X_j − X_i) dt  +  v(X_j) dt  +  √(2μ) dW_j
```

- `M`：总质量（守恒量）
- `J`：粒子数
- 注意系数是 **χM/J**，不是 χ/J —— 说明物理上起作用的是 **χM 这个乘积**，单独谈 χ 没有意义。

仓库里每个粒子权重是 1/N（总质量 M=1），用的是 `χ/N`，完全等价。

### 1.4 为什么要正则化（参数 δ）

`∇K` 在 `|x|→0` 时发散（3D 里 `|∇K| ~ 1/r²`），粒子一旦靠得极近，斥力/引力会炸掉数值格式。办法是"blob 正则化"（和涡方法里的 vortex blob 同理）：

```
K_δ(z) = K(z) · |z|²/(|z|²+δ²) = |z| / (4π(|z|²+δ²))        （DP 文、TS 文式 (15)）
```

- `δ` = **粒子的软化半径 / 最小聚集体尺度**
- `δ→0` 才逼近真实的奇异 KS；`δ` 太大则把物理"糊掉"
- 数值硬约束：`δ` 必须显著大于**平均粒子间距** `Δ=(V/N)^{1/3}`，否则近距离力不受控

### 1.5 2D 的临界质量：为什么会"爆破"

对 2D 无流情形（μ=χ=1），二阶矩满足（DP 文式 (6)）：

```
d/dt ∫|x|²ρ dx = M(8π − M)/(2π)
```

- `M < 8π`：二阶矩增长 → 密度扩散
- `M = 8π`：临界
- `M > 8π`：二阶矩在有限时间归零 → **密度爆破（blow-up）**

一般 χ 下临界质量是 `M* = 8π/χ`。**3D 没有这么干净的判据**（核的可积性变了），但"质量×敏感度超过某个阈值就聚集/爆破"的直觉仍然成立。

> 顺带一个有趣的事实：DP 文 2D 算例取 `M=16π, χ=1` → `χM=16π = 2×8π`，**刚好是临界值的两倍**（故意设在超临界区，爆破时间 t≈0.125）。
> 仓库的 3D 设定 `M=1, χ=16π` → `χM=16π`，**和 DP 文是同一个物力量**。所以这套 3D 实验其实是"照搬 2D 那个超临界强度、搬到 3D 来做"。

### 2.1 一张表看完

| 参数 | 符号/代码字段 | 论文当前值 | 物理含义 | 量纲 | 变大意味着 | 怎么改（概念上） |
|---|---|---|---|---|---|---|
| 剪切幅度 | `σ`（仓库里叫 `level`/`sigma`） | 训练 8 点 15…150（对数）；测试 10…200 | 流场强度，x 方向平流 | 1/时间 | 剪切更强、云拉得更长、误差放大 | 换 `level` 列表即可（不需改模型结构） |

| 终止时间 | `T` / `final_time` | **0.02** | 预测多长之后的分布 | 时间 | 所有效应（剪切/扩散/趋化）同时放大 | 改 `Protocol.final_time`，并保持 `dt | T` |

| 粒子数 | `N`（`n_train`/`n_eval`） | 15k / 10k / 100k | 经验测度分辨率、统计噪声 | — | 噪声下降、成本 O(N²) | 两者都可改 |
| 初始半径 | `R₀` | **1.0**（单位球均匀） | 初值支撑 = 总质量来源 | 长度 | 质量大、聚集强，同时也改变初值尺度 | `unit_ball(n, R₀, rng)` |
| 维度 | `d` | 3（另有 2D/4D） | 核的形式与 Green 函数 | — | — | 换 preset |
| 流场类型 | — | 层流剪切 | 见 §4 | — | — | 需新代码（不在本次范围） |

### 2.2 三个"位移尺度"——理解一切的钥匙

把三个物理效应换算成**同一量纲（长度）**，比较它们在一个时间窗 T 内各自能移动多少：

| 效应 | 位移尺度 | 公式 | 当前值（T=0.02, μ=1, χ=16π, R₀=1） |
|---|---|---|---|
| 剪切 | `D_s` | `σT` | σ=10 → 0.2；σ=15 → 0.3；σ=200 → **4.0** |
| 扩散 | `D_μ` | `√(2μT)` | **0.2** |
| 趋化 | `D_c` | `χM T / (4πR₀²)` | **0.08** |

> 趋化位移的来历：对均匀球（质量 M、半径 R₀），球内 `∇c = −M r/(4πR₀³)`，所以边缘处漂移速度 `χM/(4πR₀²)`，乘 T 即 `D_c`。

**结论：当前设置是 `D_s : D_μ : D_c = 0.3–4.0 : 0.2 : 0.08`。**

- 在训练起点 σ=15，剪切 ≈ 扩散 ≫ 趋化；
- 到 σ=200，剪切是趋化的 **50 倍**；
- **趋化在整个实验里都是最弱的一项**——这解释了为什么论文 Figure 3 里的终态是"弥散的锥形云"而不是"聚集成一个尖峰"。

这条结论对后续选题非常重要：**这套实验其实主要在考"强剪切下的分布输运"，KS 的聚集物理只被轻轻点了一下。**

### 2.3 为什么误差在 σ 大时爆炸（机制）

x 方向位移 `Δx = σT·e^{−(y²+z²)}`。它对横向坐标的敏感度是

```
∂Δx/∂(y,z) = 2σT·(y,z)·e^{−(y²+z²)}   ∝ 2σT
```

σ=200 时放大因子 ≈ **8**：y/z 方向 1% 的误差 → x 方向 8% 的位置误差。这就是 TS 文说的 "singular perturbation regime"，也是 Meanflow 一步生成器在 σ>150 崩掉的力学原因。

### 2.4 数值约束（改参数前必须知道）

| 约束 | 数值 | 说明 |
|---|---|---|
| δ vs 间距 | `δ ≥ 3Δ`，`Δ=(4πR₀³/3N)^{1/3}` | N=15k → Δ=0.065；N=100k → Δ=0.035。当前 δ=0.1 只比 Δ 大 1.5–2.9 倍，**已经偏"硬"** |
| dt vs 稳定性 | 粗略 `dt ≲ δ²/(χ)` | 当前 δ²/χ = 2×10⁻⁴ ≪ 0.005，靠"正则化 + 极短时间"撑住，不是严格稳定 |
| dt vs T | `T/dt` 必须为整数 | `Protocol.__post_init__` 强制校验 |
| 度量分辨率 | 经验 W2 的统计下限 0.067–0.081（16–24 箱、100k 样本） | 小于 0.07 的改进测不出来（我们实测的 split-half 结果） |
| 计算成本 | 一个 100k 参考解 85 s（RTX 4060） | O(N²)，N 翻倍 → 4× |

### 2.5 "改参数"在工程上意味着什么

仓库对物理参数做了**指纹（fingerprint）**：`Protocol.metadata()` 一变，数据集签名 `dataset_signature` 就变，所有 checkpoint 立刻失效（加载时会报 "protocol mismatch"）。

所以流程只能是：

```
改参数 → 重新生成物理数据（data）→ 重新训练（train）→ 重新评测（evaluate）
```

其中**最贵的是数据**（每个 100k 参考解 85 s）。想省时间只能：
- 减少 σ 档数（20 档 → 8 档，省 17 min/参数点）
- 减少评测粒子数（但会撞上统计下限）
- 只重跑"改变的那个参数"对应的数据

## 3. 当前实验处在什么物理区间（一句话总结表）

| 区间 | 判据 | 当前 |
|---|---|---|
| 扩散主导 | `D_μ ≫ D_s, D_c` | 仅在 σ<10 附近 |
| **剪切主导** | `D_s ≫ D_μ, D_c` | **σ ≳ 20 的全部测试点** |
| 趋化主导 | `D_c ≫ D_s, D_μ` | **无**（需要 χ 提高 ~10 倍，或 T 拉长） |
| 临界/爆破 | 2D：`χM > 8π` | 3D 无解析判据；`χM=16π` 只是"照搬 2D 的超临界强度" |

## 4. 流场与维度

| 流场 | 形式 | 出处 | 特点 |
|---|---|---|---|
| 层流剪切（laminar） | `v = σ(e^{−y²−z²}, 0, 0)` | TS 文 §4.1 | 定常、无混沌、拉伸有解析结构；`σT` 直接控制位移 |
| Kolmogorov 混沌流 | `v = σ(sin2πz, sin2πx, sin2πy)` | TS 文 §4.2（`σ∈[10,100]`，10 档均匀） | 不可积、混合、无解析不变量 |
| KPP 的时变胞流 | `v = (−cos y − θcos(2πt) sin x, cos x + θcos(2πt) sin y)` | TS 文 §4.3 | 与 KS 无关，但同一套"参数化输运"思路 |

> 仓库只实现了**层流剪切**；Kolmogorov 流（TS 文 §4.2）完全缺失。这是后续补实验最直接的一个缺口。

## 5. 把网络输入从 1 个参数扩到 2 个：选哪两个？

### 5.1 先明确"两个参数"要满足什么

一个合格的第二个条件参数应该同时满足：

1. **独立**：能和 σ 张成二维，而不是与 σ 共线/退化；
2. **物理**：它本身是有物理含义的量，不是数值技巧（如 N、dt）；
3. **可测**：改变它能带来超过度量下限（0.07）的可见差异；
4. **可负担**：每加一维，数据量 × 档数。

### 5.2 用无量纲化来筛

把粒子系统按 `x = R₀ξ, t = Tτ` 无量纲化（δ̃=δ/R₀）：

```
dξ = −[χT/R₀³]·(1/N)Σ∇K̃ dτ + [σT/R₀]·g dτ + [√(2μT)/R₀]·dW̃
```

于是这个"分布族"只由 4 个无量纲数决定：

| 无量纲数 | 表达 | 当前值 | 含义 |
|---|---|---|---|
| `S` | `σT/R₀` | 0.2 … 4.0 | 剪切强度 |
| `C` | `χT/R₀³` | 1.0 | 趋化强度 |
| `G` | `√(2μT)/R₀` | 0.2 | 扩散强度 |
| `δ̃` | `δ/R₀` | 0.1 | 正则化强度 |

在 μ、T、δ、R₀ 都固定时：`S ∝ σ`，`C ∝ χ`，`G` 和 `δ̃` 是常数。

**所以只有 (σ, χ) 这一对能"各自独立地"控制两个轴。** 其它组合都退化：

| 候选对 | 在 (S, C, G) 里怎么走 | 判定 |
|---|---|---|
| **(σ, χ)** | S 独立变、C 独立变，G 固定 | ✅ **真正的二维** |
| (σ, μ) | S 变、G 变，C 固定 | ✅ 二维，但轴是"剪切 vs 扩散" |
| (χ, μ) | C 变、G 变，S 固定 | ✅ 二维，但**丢掉了主导的剪切** |
| (σ, T) | S∝T、C∝T 同时变 | ❌ **退化（同一射线）** |
| (σ, R₀) | S∝1/R₀、C∝1/R₀³ | ❌ 与 χ 近似等价，且改初值形状 |
| (σ, δ) | 只动 δ̃ | ❌ δ 是数值正则化，不是物理 |

### 5.3 推荐：(σ, χ)

**理由 1（最硬）**：由 §5.2，`(σ, χ)` 是唯一一对"独立映射到两个无量纲物理轴"的参数。

**理由 2（最有价值）**：由 §2.2，当前实验里趋化是最弱的一项（`D_c=0.08`，比扩散还小 2.5 倍）。把 χ 从 16π 提到 64π，`D_c` 就从 0.08 升到 0.32，**聚集效应第一次和剪切/扩散同量级**——这正是"KS 之所以是 KS"的那部分物理。换句话说，第二个参数选 χ，是在"把缺失的物理补回来"。

**理由 3（最便宜）**：σ 方向的数据本来就是现成的训练网格（8 点）；只需沿 χ 方向复制几份。用 4 个 χ 档 ≈ 8×4 = 32 个 (σ, χ) 组合，数据成本 ≈ 4× 现有数据。

**具体建议的网格**：

```
σ ∈ {15, 21, 30, 42, 60, 85, 120, 150}     （沿用现有 8 点对数网格）
χ ∈ {0, 8π, 16π, 32π, 64π}                  （χM=0, 0.5, 1, 2, 4 × 8π）
```

- `χ=0` 是**必须有的对照组**：纯剪切-扩散，没有任何聚集；
- `χ=8π` 恰好是 2D 临界质量（`χM=8π`），物理上是个里程碑；
- `χ=64π` 进入强聚集区，可以看"模型在强非线性下会不会崩"。
- 可再补一个 `σ=0`（纯 KS）做正交校验。

**代价估算**（本机 RTX 4060 实测外推）：4 个 χ 档 × 20 个 σ 档 × 85 s ≈ **1.9 小时数据** + 训练 4×3 min + 评测 4×1 min ≈ **2.2 小时**。若把 σ 档减到 11 档，约 **1.1 小时**。

**输入编码建议**：不要直接喂 `(σ, χ)` 原值，喂无量纲/对数量：

```
condition = ( log10(σ/σ_ref), log10(χ/χ_ref) )     或     ( log S, log C )
```

理由：网络对输入尺度敏感；对数坐标让"跨数量级"的参数网格在输入空间里均匀；而且如果以后要加入 μ 或 T，无量纲坐标可以直接复用（只需重算 `S, C, G`）。

### 5.4 次选：如果研究目标是别的

| 如果你关心的是… | 选 | 得到什么 | 代价/风险 |
|---|---|---|---|
| **预测更长的时间**（时间外推） | (σ, T) | 不同时间窗的输运 | ⚠️ 退化：S、C 同比例放大；且 T 大可能进入爆破 |
| **扩散/平滑效应** | (σ, μ) | "剪切 vs 扩散"相图，噪声更稳 | 与 T 部分等价（G=√(2μT)/R₀ 只看乘积 μT） |
| **经典 KS（无剪切）** | (χ, μ)，σ 固定小值 | 最"教科书"的 KS | 丢掉主导几何；需要重新设计初值 |
| **近奇异结构** | (σ, δ) | 正则化极限 | δ 受 N 限制，且不是物理参数 |

### 5.5 三参数怎么办？（先别急）

如果最终想要 (σ, χ, T) 三维，数据量会变成 `8 × 4 × 4 = 128` 个组合，且每个组合都要 8 份训练数据 —— 在没有更强算力之前不现实。更聪明的做法是：

- **固定无量纲数、只扫一个**：例如固定 `S/C` 比值扫整体强度；
- 或者**先做 (σ, χ) 二维**，确认趋势后，再用少量 T 档做"外推检验"（而不是全网格）。

### 5.6 实施时的四个陷阱

1. **数据量爆炸**：每加一个参数维，训练数据要按"档数"复制。建议先在 **8×4** 的小网格上验证，再扩。
2. **稀疏网格 + 尖锐相变**：如果 χ 大到出现密度尖峰，`(σ,χ)` 平面上会有一条"相变线"，网格太稀会让模型在线上失真。建议 χ 用几何级数（0, 8π, 16π, 32π, 64π），并在相变附近加密。
3. **度量分辨率**：改用二维输入后，模型的"改进"必须在 0.07 以上才有意义；若 χ 大导致分布更尖，16 箱直方图会不够，建议同步提到 24–32 箱或改用粒子级 OT。
4. **协议指纹**：改了 χ 就是换了物理模型，旧 checkpoint 全部失效，`dataset_signature` 会变——这是仓库的设计，不是 bug。
