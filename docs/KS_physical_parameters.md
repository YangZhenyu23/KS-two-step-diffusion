# KS 实验的物理参数：现状、含义与可扫描范围

> 用途：为后续研究选题做底稿。当前仓库/论文只扫描了 **σ**（剪切幅度）；本文把模型里所有物理参数的来源、含义、量级、相互制约关系，以及"如果要扫、范围该取多少、代价多大"一次说清。
> 依据：仓库 `deepparticle/particle_pipeline/{physics,protocol}.py`、`training/protocol.py`，论文 Shen et al. 2026 §4.1–4.2，DeepParticle 原文 Wang et al. 2024 §2–4，以及我们这次 KS3D 复现的实测数据。

---

## 0. 一句话结论

这套 KS 实验的完整物理参数是 **7 个**：`σ, μ, χ, δ, T, N, R₀`（+ 结构性的"维度 d"和"流场类型"）。**目前只把 σ 扫了 8+20 个点，其余 6 个全部钉死**。其中真正能改变物理图像的是 `σ, μ, χ` 三个；`δ, N, dt` 是数值参数但有硬约束；`T` 与 `σ` 不完全独立（真正进入方程的是无量纲组合 `σT`）。

---

## 1. 模型本体（先对齐公式）

3D Keller–Segel + 剪切流（水动力极限后的粒子系统，论文式 (13)–(15)）：

```
dX_j = −(χ/N) Σ_{i≠j} ∇K_δ(|X_i − X_j|) dt  +  v(X_j) dt  +  √(2μ) dW_j
K(z)   = 1/(4π|z|)                          (3D 牛顿核)
K_δ(z) = K(z)·|z|²/(|z|²+δ²) = |z|/(4π(|z|²+δ²))   (正则化)
v(x)   = σ (e^{−y²−z²}, 0, 0)               (层流剪切)
```

代码里就是 `training/protocol.py:simulate_original`（及 `physics.py:ks_simulate`）的两行：

```python
points[:,0] += dt*sigma*exp(-y²-z²)                                   # 剪切
force = -(chi/N) * Σ (X_i-X_j) * (δ²-r²)/(4π r (r²+δ²)²)              # 相互作用 = -χ∇K_δ
points += dt*force + sqrt(2*mu*dt)*randn                              # 欧拉-丸山
```

## 3. 逐参数：物理意义 + 影响 + 建议扫描范围

### 3.1 σ（剪切幅度）—— 已在扫

- **物理**：流场 `v = σ(e^{−y²−z²},0,0)`，近轴处速度 ≈ σ，随后按 `e^{−(y²+z²)}` 衰减。σ 越大，流场越"剪切化"。
- **直接后果**：一个粒子在 T 内的最大 x 位移 = `σT`（σ=15 → 0.3；σ=200 → 4.0）。这解释了为什么 σ↑ 时云团在 x 方向被拉成 4–5 长的锥形（我们实测 σ=160 时 extent_x = 4.85）。
- **为什么误差在 σ>150 爆炸**：x 位移对横向坐标的敏感度是
  `∂(Δx)/∂(y,z) = 2σT·(y,z)·e^{−(y²+z²)}`，σ=200 时 ≈ 8。
  也就是说 **y/z 方向 1% 的误差会被放大成 8% 的 x 方向位置误差**。这就是论文说的 "singular perturbation regime"（奇异扰动区）：σ 越大，map 越接近一个"近似不可逆的强剪切"，一步生成器（Meanflow）的横向误差被线性放大。
- **当前范围**：训练 [15,150]（8 点对数），测试 10–200（20 点）。
- **建议扩展**：`σ ∈ {0, 5, 10, …, 400, 600}`。
  - σ=0 是纯 KS（只有趋化+扩散），是**必须有的对照**（现在没有！）；
  - σ=300–600 会进入 `σT ≫ 支撑` 的强剪切区，能看到"误差随 σ 线性增长"是否成立；
  - 代价：每档 100k 参考解 85 s，20 档 ≈ 28 min。

### 3.2 μ（扩散系数）—— 固定 1

- **物理**：细菌的随机游走。特征扩散长度 `L_μ = √(2μT) = 0.2`（当前）。
- **作用**：μ 越大，云团越弥散、τ=local 密度越低 → 趋化聚集越弱、数值上越稳定；μ→0 时 KS 更容易形成尖峰/有限时间爆破（2D 有 8π/χ 的临界质量判据，见 Wang et al. 式 (3) 附近）。
- **与 σ 的关系**：`L_μ` 与剪切位移 `σT` 的比值决定云团的"长宽比"：σT/L_μ = 0.3/0.2=1.5（σ=15）→ 4.0/0.2=20（σ=200）。
- **建议范围**：`μ ∈ {0.05, 0.1, 0.25, 0.5, 1, 2, 4}`。
  - μ 调大 → 问题变"平滑"，是检验模型泛化到**不同扩散**的干净实验；
  - μ 调小（≤0.1）→ 云更紧、更尖，直方图网格会被"撑爆"（见 §4 的网格问题），且可能进入爆破前区间。
- **组合实验**：固定 `σT/L_μ` 做无量纲相似扫描（见 §4.2），比单参数扫更有物理意义。

### 3.3 χ（趋化敏感度）—— 固定 16π

- **物理**：趋化强度。单粒子平均漂移尺度 ≈ `χ·ρ₀`，其中 ρ₀ = M/V = 3/(4πR₀³) ≈ 0.239（R₀=1）。
  → 当前 `χρ₀ ≈ 12.0`（1/时间），乘以 T=0.02 得 **0.24 的特征聚集位移**。
- **关键判据**：剪切位移 `σT` 与聚集位移 `χρ₀T` 的比值
  `R = σ/(χρ₀) ≈ σ/12`。
  - σ=10 → R≈0.8（**趋化主导**）
  - σ=15 → R≈1.25（两者同量级 ← 训练起点正好在这里，不是巧合）
  - σ=200 → R≈17（**剪切主导**）
  这个比值是解释"为什么 σ 是唯一有效的条件参数"的最简洁答案。
- **建议范围**：`χ ∈ {0, 4π, 8π, 16π, 32π, 64π}`（即 χρ₀ ≈ 0, 3, 6, 12, 24, 48）。
  - χ=0 → 纯平流-扩散（没有聚集），是**判定"模型是否只在学剪切"的对照组**；
  - χ 增大 → 聚集更紧、局部密度更高、δ 的正则化作用更关键，数值上更容易出现尖峰；
  - 文献里 2D 的临界质量是 `M* = 8π/χ`，3D 无此简洁判据，但定性趋势一致。

### 3.4 δ（核正则化）—— 固定 0.1

- **物理**：把 `1/|z|` 在小距离处抹平，等价于给每个粒子一个"软核半径"。它决定聚集体能达到的最小尺度，也是数值稳定的关键（否则近距离力发散）。
- **硬约束（很重要）**：δ 必须明显大于**平均粒子间距** `Δ = (V/N)^{1/3}`：
  - N=15,000, R₀=1 → Δ = 0.065
  - N=100,000, R₀=1 → Δ = 0.035
  当前 δ=0.1 只比 Δ 大 1.5–3 倍，**属于偏"硬"的设定**。若 δ 再小，个别粒子对会产生 O(1/dt) 的伪力、乃至数值爆炸。
- **建议范围**：`δ ∈ {0.05, 0.1, 0.2, 0.4}`，且**必须**同时满足 `δ ≥ 3Δ`（想用更小的 δ 就得同时增大 N）。
- **科学价值**：δ 扫的是"物理正则化 → 近似奇异核"的极限，是衡量模型是否学到**近奇异结构**的好探针（论文的核心卖点之一）。

### 3.5 T（终止时间）与 dt

- **物理**：T 是"预测多长时间后的分布"。当前 T=0.02 很小（4 个时间步），本质上是一个**短时**问题。
- **与 σ 的耦合**：方程里只出现 `σT`（剪切位移）和 `χρ₀T`、`√(2μT)`。**固定 T 扫 σ 其实是在扫"剪切位移"**。
- **建议**：要么固定 σ 扫 T ∈ {0.005, 0.01, 0.02, 0.05, 0.1}（考"时间外推"），要么做 `σT = const` 的**相似性检验**（若模型真学到物理，应该看到近似自相似的结果）。
- **dt**：当前 4 步，偏粗。若做 T 扫描，建议 dt ≤ 0.0025（T/dt ≥ 8–20），否则离散误差会掩盖物理差异。KS 的显式格式稳定性大致要求 `dt ≲ δ²/χ`（当前 δ²/χ = 2e-4 ≪ 0.005，**说明当前格式在稳定性上其实是靠正则化+短时间撑住的**，不是严格稳定）。

### 3.6 N（粒子数）与 R₀（初始半径）

- **N**：既是数值分辨率，也是"标签噪声"来源。我们实测：把同一个 100k 参考云随机对半切成两个 50k 样本，它们之间的 W2 就有 **0.067–0.081** —— 这是任何经验 W2 的**统计下限**。任何小于这个数的"改进"都是噪声。
- **R₀**：改变总质量 `M=4πR₀³/3`，进而改变 ρ₀ 与 χρ₀，等价于缩放 χ。所以 R₀ 与 χ 在物理上是**近似可交换的**（只差一个因子），不建议同时扫。
- **建议**：N 不扫（固定在 15k/100k），R₀ 固定 1；若要做"质量依赖"，用 χ 代替。

| 变体 | 论文出处 | 仓库是否实现 | 说明 |
|---|---|---|---|
| 2D KS（对数核） | Wang 2024 §3；仓库 `ks2d` 预设 | ⚠️ 有代码但无训练/结果 | 2D 有解析临界质量 8π/χ，物理最经典 |
| 3D 层流剪切（当前） | Shen §4.1 | ✅ | 唯一有完整结果的 |

## 4. 无量纲分析与"哪个参数值得扫"

### 4.1 三个特征尺度

| 尺度 | 公式 | 当前值（σ=160, μ=1, χ=16π, T=0.02） |
|---|---|---|
| 剪切位移 | `S = σT` | 3.2（σ=10 时 0.2） |
| 扩散长度 | `L = √(2μT)` | 0.20 |
| 聚集位移 | `A = χρ₀T`（ρ₀=3/(4πR₀³)） | 0.24 |
| 初始半径 | `R₀` | 1.0 |

### 4.2 三个无量纲数

1. **剪切/聚集**：`R₁ = σ/(χρ₀)` —— σ=10 时 0.8，σ=200 时 17。**决定"谁主导"**。
2. **剪切/扩散**：`R₂ = σT/√(2μT) = σ√(T/2μ)` —— σ=160 时 16。**决定云团的长宽比**。
3. **正则化/间距**：`R₃ = δ/(V/N)^{1/3}` —— 1.5（15k）或 2.9（100k）。**决定数值是否可信**。

### 4.3 由此得到的三条设计原则

- **要测"物理泛化"，就扫 R₁**：要么动 σ（已做），要么动 χ 或 μ。**动 χ 比动 σ 更有信息量**，因为它改变的是聚集强度而不是几何拉伸。
- **要测"时间外推"，就扫 T 同时保持 R₁、R₂ 不变**（σ ∝ 1/T, μ ∝ 1/T）。
- **别扫出 R₃ < 1 的区间**（δ 太小时数值先坏，与模型能力无关）。

## 5. 数值/度量上的硬约束（设计实验前必须知道）

| 约束 | 数值 | 来源 |
|---|---|---|
| 经验 W2 的统计下限 | **0.067–0.081**（16–24 箱，100k 样本） | 我们实测的 split-half |
| 直方图网格 | 以参考云 min 为原点、`ptp/16` 为箱宽，越界点不裁剪 | `run_evaluation.measures_for` |
| 单个 100k 参考解耗时 | **85 s**（RTX 4060，chunk=256，峰值 1.92 GiB） | 复现实测 |
| 单个 15k 训练云 | 2.1 s | 同上 |
| 单个 10k 评测云 | 0.8 s | 同上 |
| 训练一个 seed（MF1000+DP1000+MFDP500） | ~60–90 s | 同上 |
| 20 档 × 3 seed × 9 云 的精确 OT 评测 | 61 s（workers=4） | 同上 |

> **推论**：任何"改进 < 0.07"的实验，在 16 箱/100k 这套度量下都不可分辨。想看到更细的差异，必须换更细的度量（更细网格 + 更多粒子），否则做参数扫描是白做。

## 6. 建议的后续实验方向（按性价比排序）

### 方案 A：补"对照组"（最便宜，最有说服力）

- 加 **σ=0**（纯 KS）与 **χ=0**（纯剪切）两个极端。
- 目的：证明模型不是在"只学剪切"。目前论文里没有这两个点，是审稿人最可能问的。
- 代价：2 个参数档 ≈ 3 分钟数据 + 3 分钟训练 + 1 分钟评测。

### 方案 B：χ–σ 二维相图（物理上最有意思）

- `χ ∈ {0, 8π, 16π, 32π, 64π}` × `σ ∈ {0, 50, 100, 200}`（5×4 = 20 组）。
- 预期：存在一条"剪切主导 → 趋化主导"的分界线，大致在 `σ ≈ χρ₀`，即 σ* ≈ 3, 6, 12, 24, 48。
- 代价：每格 8 训练 + 11 评测（或复用已有 σ 网格），约 20 × 20 min ≈ 7 小时（可夜间跑）。
- 价值：这是**目前没人做过**的图（论文只在 σ 一个方向上看），天然是一个新结果。

### 方案 C：δ 扫描（考"近奇异结构"）

- `δ ∈ {0.05, 0.1, 0.2, 0.4}`，配 N=100k 保证 δ/Δ ≥ 3。
- 预期：δ 越小，分布越尖，直方图度量越吃亏，可以顺带论证"为什么需要粒子级度量"。
- 代价：4 档 ≈ 1 小时。

### 方案 D：Kolmogorov 流（论文 §4.2 的缺口）

- 需要新写 `v = σ(sin2πz, sin2πx, sin2πy)` 的粒子推进器（约 20 行），并重跑数据。
- 价值：补齐论文的第二组 KS 实验；混沌流下没有解析不变量，更能体现生成模型的价值。
- 代价：代码 0.5 天 + 数据/训练 2–3 小时。

### 方案 E：时间外推（T 扫描）

- `T ∈ {0.01, 0.02, 0.05, 0.1}`，dt=0.0025。
- 注意：T 变大后 KS 可能进入聚集/爆破区间，要先做数值稳定性检查。
- 价值：与"参数外推"互补，是另一个 generalization 维度。
