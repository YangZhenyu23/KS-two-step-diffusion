## 3. 决定性判据：论文的数低于这个指标的统计下限

在同一张 16 箱/轴网格上，把我们的 100k 参考云**随机对半切开**（两个 50k 独立样本，来自同一个分布），它们之间的 W2 就是这套指标能分辨的"零点"：

| σ | 16 箱 | 24 箱 |
|---:|---:|---:|
| 20 | 0.0746 | 0.0673 |
| 100 | 0.0747 | 0.0676 |
| 160 | 0.0807 | 0.0705 |
| 200 | 0.0815 | 0.0722 |

**两个同一分布的独立样本之间就有 0.067–0.081。** 而论文报告的 DP 精修值是 0.0047–0.0214 —— 比"自己和自己比"还小 3–15 倍。

这在数学上不可能：任何经验测度之间的 W2 都不可能低于有限样本自身的涨落。所以论文的 W2 **不是**"生成云 vs 参考云在物理坐标下的经验 W2"，论文正文也没有给出这套归一化/离散化的定义。

**旁证**：同一条研究线的 DeepParticle 原文（Wang et al. 2024）Table 2 也是这个量级——3D laminar、A=50 报 0.0217，A=130 报 0.0946，同样是"20 箱直方图 + 10⁶ 生成 vs 10⁴ 参考"。也就是说这个"很小的 W2"是该系列论文一贯的度量约定，而不是我们这次的实现问题。

## 5. 第二层原因：架构确实不同

论文 §3.4 与仓库 `_architecture(name, method)` 的对照：

| | 论文 | 仓库 / 我们 |
|---|---|---|
| Meanflow | width 64、depth 5、SELU、**sinusoidal embeddings of (r,t,σ)**、light skip connections、small-gain linear head | width 64、**3 个隐层**、SELU、**原始标量直接 concat**、无 skip、普通 Linear 头；条件用 `log10σ` |
| DP 修正器 | near-identity ResNet，depth 4、width 64、**SiLU + LayerNorm** | 3 层 SELU、**无 LayerNorm**、零初始化输出头；混合时 α=10 |
| DP 输入 | `[x, σ]`（d+1） | 同（d+1，一致） |
| 训练预算 | T_dp 步（论文未给具体值） | MF 1000 / DP 1000 / 混合 500+500 |

也就是说，仓库复现的是**它自己演化后的版本**（"d+1 compact corrector + original_tuned MF"），不是论文那一版的网络。这会**额外**拉开差距，但解释不了 25 倍——因为第 3 节的统计下限是硬约束。

## 6. 结论

| 层面 | 判定 |
|---|---|
| 按仓库流程跑通（数据→训练→评测→出图） | ✅ 全部完成，耗时 34 分钟 |
| 与仓库保存的历史数值 | ✅ 逐点复现（最大 0.4% 相对偏差，180/180 行） |
| 与论文的**趋势/定性结论** | ✅ 复现：σ≤120 平稳、σ>150 Meanflow 爆炸、DP 精修显著更平；曲线相关 0.94 / 0.99 |
| 与论文的**绝对数值** | ❌ 未复现，系统偏大 4–35 倍；且论文数值低于该指标自身的统计噪声下限，说明口径不同 |
| 与论文的**网络结构** | ❌ 仓库用的不是论文那版网络（无正弦嵌入/跳连/LayerNorm，层数不同） |

**一句话**：这次复现的是"仓库对论文的复现"，不是"论文本身"。仓库的代码+数据能自洽地给出 Figure-2 同形状的曲线，但论文表格里的那些小数不能用这套管线复算出来——除非拿到论文自己的数据与评估脚本。

### 下一步（若要真正对上论文数字）
