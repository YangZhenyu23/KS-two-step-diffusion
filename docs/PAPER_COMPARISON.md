- 我们的复现：`repro_ks3d/`（KS3D，100k 粒子、16 箱/轴精确直方图 OT）

## 3. 关于"论文数值低于统计下限"的论证：**原论证已失效，修正如下**

> ⚠️ **本节曾以"16 箱直方图劈半的 $W_2$"作为统计下限，论证论文数值不可能。该论证后来被证明无效**，原因见下。修正后的判断保留在 §3.3。

### 3.1 原论证（已失效）

把 100k 参考云随机对半切成两个 50k 样本，测其 16 箱直方图 $W_2$：

| σ | 16 箱 | 24 箱 |
|---:|---:|---:|
| 20 | 0.0746 | 0.0673 |
| 100 | 0.0747 | 0.0676 |
| 160 | 0.0807 | 0.0705 |
| 200 | 0.0815 | 0.0722 |

据此曾判断：论文报 0.0047–0.0214，比"自己和自己比"还小 3–15 倍，数学上不可能。

### 3.2 为何失效：两个缺陷

**缺陷一：该数值 94% 是量化伪影，不是统计下限。**

后续实验（`METRIC_CORRECTION.md`）用"保持粒子位置不变、仅按其箱计数的多项分布重抽箱内分配"构造了物理上完全相同的两团云，其 16 箱 $W_2$ 为 **0.0428**，而总底噪为 **0.0455**——即 **94% 来自分箱**。用被量化污染的数字作统计下限，论证不成立。

**缺陷二：用的是 50k 子样本，而非 100k。**

劈半使抽样噪声放大 $(2)^{1/3}=1.26$ 倍。该数值既偏高（量化）又偏高（子样本）。

### 3.3 修正后的估计

以粒子级实测（`results/fullscale/particle_metric/particle_floor_full.json`，$m=3000$ 五点）按 $\varepsilon\propto m^{-1/3}$ 外推到 $m=10^5$（缩放因子 $0.311$）：

| σ | μ | $m{=}3000$ 实测底噪 | **外推至 $m{=}10^5$** | 论文 DP 值 | 论文/外推 |
|---:|---:|---:|---:|---:|---:|
| 10 | 0.1 | 0.0897 | **0.0279** | — | — |
| 100 | 1 | 0.1229 | **0.0382** | 0.0059 | **6.5×** |
| 200 | 0.1 | 0.0945 | **0.0294** | 0.0214 | **1.4×** |
| 200 | 10 | 0.2310 | **0.0718** | 0.0214 | 3.4× |

**修正后的判断**：

- σ=100 处论文仍低于外推下限 **6.5 倍**，可疑；
- σ=200 处只低 **1.4 倍**，**在估计误差范围内，不足以断言不可能**。

**关键限定**：0.0382 等数值是**外推**而非实测。要确证需实测 $m=10^5$ 的粒子级底噪，代价为 74.5 GiB 内存与约 21 小时/次 OT，本机不可行。

### 3.4 结论状态：未知而非不可能

**论文数值为何这么小，目前仍未知。** 候选解释（均无证据支持）：

1. **Sinkhorn 熵正则**：论文 §2 提到实践中"often estimated on mini-batches and accelerated via entropic regularization"，但未声明自身是否使用。熵正则会平滑 OT 解，可压低数值。
2. **更小的 $m$**：方向相反（$m$ 小使 $W_2$ 更大），不成立。
3. **坐标归一化**：已测（`scale_hypothesis.py`）。需要除以云对角线的 2.2–4.2 倍且该比值不恒定；最好的情况仍差 3.3 倍，**无法解释**。
4. **论文实现或报告有误**：无法排除。

**旁证**：同研究线的 DeepParticle 原文（Wang et al. 2024）Table 2 也是这个量级——3D laminar、A=50 报 0.0217，A=130 报 0.0946——说明"很小的 $W_2$"是该系列的度量约定，而非本仓库实现的缺陷。

## 5. 第二层原因：架构确实不同

论文 §3.4 与仓库 `_architecture(name, method)` 的对照：

| | 论文 | 仓库 / 我们 |
|---|---|---|
| Meanflow | width 64、depth 5、SELU、**sinusoidal embeddings of (r,t,σ)**、light skip connections、small-gain linear head | width 64、**3 个隐层**、SELU、**原始标量直接 concat**、无 skip、普通 Linear 头；条件用 `log10σ` |
| DP 修正器 | near-identity ResNet，depth 4、width 64、**SiLU + LayerNorm** | 3 层 SELU、**无 LayerNorm**、零初始化输出头；混合时 α=10 |
| DP 输入 | `[x, σ]`（d+1） | 同（d+1，一致） |
| 训练预算 | T_dp 步（论文未给具体值） | MF 1000 / DP 1000 / 混合 500+500 |

也就是说，仓库复现的是**它自己演化后的版本**（"d+1 compact corrector + original_tuned MF"），不是论文那一版的网络。这会**额外**拉开差距，但解释不了 25 倍——因为 §3 的修正分析显示，即使扣除量子化与尺度效应，差距仍有 3–20 倍，远超架构差异的合理范围。

## 6. 结论

| 层面 | 判定 |
|---|---|
| 按仓库流程跑通（数据→训练→评测→出图） | ✅ 全部完成，耗时 34 分钟 |
| 与仓库保存的历史数值 | ✅ 逐点复现（最大 0.4% 相对偏差，180/180 行） |
| 与论文的**趋势/定性结论** | ✅ 复现：σ≤120 平稳、σ>150 Meanflow 爆炸、DP 精修显著更平；曲线相关 0.94 / 0.99 |
| 与论文的**绝对数值** | ❌ 未复现，系统偏大 15–25 倍（粒子级口径）。差距**无法**用坐标尺度变换解释（需 2.2–4.2 倍且不恒定），亦不足以断言论文低于统计下限（原论证已失效，见 §3）。**根本原因未知** |
| 与论文的**网络结构** | ❌ 仓库用的不是论文那版网络（无正弦嵌入/跳连/LayerNorm，层数不同） |

**一句话**：这次复现的是"仓库对论文的复现"，不是"论文本身"。仓库的代码+数据能自洽地给出 Figure-2 同形状的曲线，但论文表格里的那些小数不能用这套管线复算出来——除非拿到论文自己的数据与评估脚本。
