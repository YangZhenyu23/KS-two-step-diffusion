# 双物理参数扩展实验报告

> 在 KS3D 两步扩散框架上，把网络输入从单参数 σ 扩展到双参数 (σ, μ)，用拉丁超立方抽样降低数据量，并定量评估第二个参数是否带来收益。

---

## 0. 先纠正一件事：`kappa` 不在 KS 方程里

任务书里提到的第二个参数是 `kappa`。核对代码后必须指出：

| 符号 | 出现在哪 | 代码中的含义 |
|---|---|---|
| `kappa` (κ) | **仅 KPP 分支** | KPP 的扩散系数，`s = −log₂κ`（`protocol.py:105`、`physics.py:38`） |
| `mu` (μ) | KS 方程 | **真正的扩散系数**，噪声项 `√(2μ·dt)`（`core.py`、`protocol.py:39`） |
| `sigma` (σ) | KS 方程 | **剪切/对流幅值**，`x += dt·σ·exp(−y²−z²)` |
| `chi` (χ) | KS 方程 | 趋化（聚集）强度，`16π` |

KS 方程里**没有 κ**。任务书说"σ 控制扩散、κ 控制对流"，实际是**反的**：σ 是对流，μ 才是扩散。

因此第二个参数选 **μ**：它才是 KS 里真正的扩散系数，与 KPP 的 κ 扮演同一个物理角色，符合任务书"扩散系数/热传导率类参数"的意图，且不需要虚构一个不存在的符号。

---

## 1. 为什么 μ 是合理的第二个参数

四条判据，全部量化。

### 1.1 与 σ 在方程中角色不同（正交性）

无量纲化（`x = R₀ξ, t = Tτ`）后，分布族只由 4 个无量纲数决定：

```
S = σT/R₀          （剪切）     ← 只由 σ 控制
C = χT/R₀³         （趋化）     ← 固定 = 1.0
G = √(2μT)/R₀      （扩散）     ← 只由 μ 控制
δ̃ = δ/R₀          （正则化）   ← 固定 = 0.1
```

`χ, T, δ, R₀` 全部固定时，`(σ, μ)` **各自独立地映射到 S 和 G**，构成真正的二维参数空间。这是 `(σ, κ)` 做不到的（κ 不在方程里），也是 `(σ, T)` 做不到的（T 同时放大 S 和 C，退化成一条射线）。

### 1.2 物理上互补（几何证据）

对 100 格逐格测量云的几何量：

| 变化方向 | x 方向标准差 | yz 半径 p95 |
|---|---|---|
| σ: 10 → 200（μ=0.1 固定） | 0.481 → 0.856（**+78%**） | 1.007 → 0.991（**−2%**） |
| μ: 0.1 → 10（σ=10 固定） | 0.481 → 0.795（+65%） | 1.007 → 1.925（**+91%**） |

**σ 只拉长 x 方向（改变各向异性），μ 只让云各向同性地变胖（改变整体尺度）。**
两者作用在几何上不同的自由度，不存在退化。右图（`continuity_plot.png` 第三格）显示：固定 μ 的三条曲线沿 x 轴（各向异性）移动，而 μ 的取值把曲线沿 y 轴（展宽）平移——两组方向近乎垂直。

### 1.3 可测（超过噪声基底）

在 σ=100、μ=1、N=20k 处，两种参数的可分辨阈值：

| 方向 | 可分辨相对变化 | 依据 |
|---|---|---|
| σ | **约 1.4–3%** | 信号线性斜率 3.60，噪声 0.093 |
| μ | **约 25%** | 信号斜率 0.33 |

μ 的灵敏度比 σ 低约 11 倍，但仍远超零——μ 从 0.1 变到 10 时 W2 达到 0.48，是噪声的 5 倍。这在物理上合理：`μT = 0.02` 相对 `R₀² = 1` 很小，扩散本来就只是弱扰动。

### 1.4 可负担

μ 方向 10 档 × σ 方向 10 档 = 100 格。实测 **190 秒**生成全部 100 格（N=15k，RTX 4060）。这个成本足以做完整网格，从而支持"留出验证"——比只跑 LHS 20 格更有说服力。

### 1.5 为什么不选其他候选

| 候选 | 问题 |
|---|---|
| `kappa` | 不属于 KS 方程（KPP 专用） |
| `chi` (χ) | 物理上更"有意思"（补回聚集物理），但 `χ` 大到 `64π` 时密度出现尖峰，16 箱直方图分辨不了，需要改度量 |
| `T` (终止时间) | 退化：`S ∝ T`、`C ∝ T` 同时变，参数空间塌成一条射线 |
| `delta` (δ) | 数值正则化，不是物理参数 |

## 2. 参数取值：各取多少，为什么

### 2.1 σ：10 个值

```python
SIGMA_GRID = [10, 15, 20.84, 28.96, 40.24, 55.91, 77.69, 107.95, 150, 200]
```

- 中间 8 个**正是上游单参数训练的原始 8 点网格**（`1.5 × 10^(1+(k-1)/7)`，`k=1..8`）。这保证 `μ=1` 那一行与本仓库已有的单参数基线**协议完全一致**，可以直接对比。
- 两端各补 1 点（10 和 200）——上游评测范围的**两个端点**，让二维盒子覆盖 σ 的全域。

### 2.2 μ：10 个值，对数等距跨一个数量级

```python
MU_GRID = [0.1, 0.1585, 0.2512, 0.3981, 0.6310, 1.0, 1.5849, 2.5119, 3.9811, 10.0]
```

- **几何级数跨 2 个数量级（0.1 → 10，各向 10 倍）**。理由：扩散位移 `G = √(2μT)` 是 μ 的平方根，所以 μ 跨 100 倍时 G 跨 10 倍（0.063 → 0.632），与 σ 的位移范围 `S = 0.2 → 4.0`（20 倍）量级相当。
- **μ = 1.0 居中**，正是上游协议值。这一格与本仓库基线**逐位一致**。
- **为什么不是更多档**：μ 的可分辨阈值约 25%（§1.3），对数等距 10 档的相邻间距是 `10^0.222 = 1.67` 倍，已经接近但略大于阈值——再加密会得到"看起来不同、实际在噪声里"的格点。

### 2.3 为什么两边都取 10 而不是不同数量

LHS 的构造要求网格是**方形**（见 §3.3），才能保证每个 sigma 层和每个 mu 层恰好被抽中相同的次数。10×10 也正好是"100 格全跑只要 3 分钟"的规模。

## 3. 卡宾方（拉丁超立方抽样，LHS）

### 3.1 是什么

拉丁超立方抽样（Latin Hypercube Sampling, LHS）由 McKay、Beckman 和 Conover 在 1979 年提出。构造方式：

- 把每一维的取值范围等分成 `n` 个区间；
- 在每一维的**每个区间里恰好放一个样本点**；
- 各维的区间分配随机独立。

等价说法：把 `n` 个点按第 `k` 维坐标排序后，第 `k` 维的坐标恰好是 `n` 个区间代表值的某个**排列**。

### 3.2 为什么用它

**（1）一维边缘分布精确均匀。**
普通随机抽样只在期望意义上均匀，实际会成团（clumping）和留空（voids）。LHS 保证每一维的每个区间都恰好有一个点——这是**确定性**的，不是概率性的。

**（2）方差更小。**
对单调或近似可加的目标函数，LHS 的均值估计方差是 `O(n⁻¹)`，而独立随机抽样是 `O(n⁻¹ᐟ²)`（Stein 1987）。同样的样本量，LHS 的统计误差下降一个量级。

**（3）空间填充更好。**
因为每维每层都有点，LHS 天然避免了"某一片参数区域完全没采样"的情况——这对训练回归型网络至关重要，空洞会让网络在那片区域胡乱外推。

### 3.3 离散网格上的 LHS 实现

本问题是**离散网格**（10×10），不是连续域。取 `n = k·A`（`A = 10` 层，`k = 2`）：

- 生成 `k` 个 `{0..9}` 的独立随机排列 `π₁, π₂`；
- 第 `s` 个点取第 `s` 层 sigma，配对 `π_s[i]` 层的 mu。

由构造**必然**得到：每个 sigma 层恰好 2 个点，每个 mu 层恰好 2 个点。这就是离散版拉丁超立方性质。

在满足该性质的**所有**设计中，再用**模拟退火**挑最大化最小成对距离（maximin 准则，Johnson–Moore–Ylvisaker 1990）的那一个。maximin 保证设计空间填充——没有两个训练条件冗余，网络看到的是整个参数方块而不是一条对角带。

实现见 `twoparam/lhs.py`：24 次重启 × 4000 次退火迭代。

## 4. 训练结果

### 4.1 网络结构

| | 单参数（上游） | 双参数（本实验） |
|---|---|---|
| 输入维数 | 6（z, r, t, log σ） | **7**（z, r, t, log σ, log μ） |
| 宽度 | 64 | 64 |
| 隐层 | 3 × SELU | 3 × SELU |
| 输出 | 3 | 3 |
| 其余 | — | 完全相同 |

**只多一个输入列**，其它一切不变。这样与基线的对比是纯粹的"多看一个参数"的效应，不是架构差异。

### 4.2 全网格泛化（LHS-20 训练，100 格评测）

| 指标 | 数值 |
|---|---:|
| 训练集 20 格 平均 W2 | 0.2800 |
| **留出集 80 格 平均 W2** | **0.2717** |
| 全网格 100 格 平均 W2 | 0.2734 |
| 全网格最大 W2 | 0.6618 |
| μ=1 切片 平均 W2 | 0.2245 |
| OT 认证 | 100/100 最优 |
| 最大质量残差 | `1.1e-16` |
| 最大对偶间隙 | `1.3e-12` |

**留出集（0.2717）几乎等于训练集（0.2800），甚至略低。** 这说明 LHS-20 充分覆盖了参数空间——20 个点训练出的网络在 80 个从未见过的格点上泛化无衰减。

### 4.3 与单参数基线的对比（关键）

**这里的对比必须小心。** 上游基线（W2 ≈ 0.35）用的是 100k 粒子、20 个 σ、不同的训练预算，与本实验（20k 粒子、10 个 σ）不可直接比较。所以我在**完全相同条件下**训练了一个单参数对照模型（同样 20k 粒子、同样格点数、同样每格更新数），只让它看 σ。

| 每格更新数 | 单参数 W2（72 个双留出格） | 双参数 W2 | 相对改进 |
|---:|---:|---:|---:|
| 200 | 0.2620 | **0.2460** | **−6.1%** |
| 600 | 0.2260 | **0.1827** | **−19.1%** |
| 1500 | 0.2091 | **0.1873** | **−10.4%** |

**在所有预算档位上，双参数模型都优于单参数模型**，最佳改进 19.1%（每格 600 次更新时）。

### 4.4 一个必须记录的失败尝试

第一次对比用**固定 1000 步**（不按格点数缩放），结果双参数模型**输了 67%**（0.448 vs 0.322）。诊断发现原因是**预算稀释**：20 个格点分 1000 步 = 每格 50 步，而单参数 10 格分 1000 步 = 每格 100 步。加大到 8000 步后，双参数模型立刻反超（0.272 vs 0.448）。

**这个坑值得记下来**：多参数实验里，"固定总步数"是错误的对齐方式，必须按**每格更新数**对齐。我第一次的负数结论完全是预算假象。

### 4.5 μ 到底带来了什么

在 72 个双留出格上，按 μ 距 1 的距离分组：

| \|log10 μ\| | n | 单参数 W2 | 双参数 W2 | 增益 |
|---:|---:|---:|---:|---:|
| 0.20 | 16 | 0.1837 | 0.2332 | −0.049 |
| 0.40 | 16 | 0.1991 | 0.2332 | −0.034 |
| 0.60 | 16 | 0.2364 | 0.2871 | −0.051 |
| 0.80 | 8 | 0.1522 | 0.3288 | −0.177 |
| **1.00（μ=10）** | 16 | 0.3771 | **0.3194** | **+0.058** |

这张表来自**预算匹配不足**的那一版（每格 400 步），所以整体偏负。但它揭示了一个真实的物理结构：

**单参数模型的误差随 μ 偏离单调上升**（0.184 → 0.199 → 0.236 → **0.377**，2.05 倍）。这正是"不知道 μ"的代价——它把 μ=10 的云当成 μ=1 的云来生成，误差翻倍。

而双参数模型**在 μ=10 这个极端处赢了 15.3%**——恰恰是单参数模型最不擅长的区域。在预算充足时（§4.3 的 600 档），这个优势扩展到整体。

## 5. 参数连续性（关键问题）

### 5.1 能否直接观察：能

三个层次的数值证据（详见 `docs/CONTINUITY.md`）：

**（a）网格细化。** 固定 σ=100、μ=1，把参数步长减半两次：

| σ 步长 | h | W2 实测 | W2 扣除噪声 | **W2_corr/h** |
|---:|---:|---:|---:|---:|
| 20.0 | 0.0792 | 0.2914 | 0.2761 | **3.49** |
| 10.0 | 0.0414 | 0.1843 | 0.1590 | **3.84** |
| 5.0 | 0.0212 | 0.1286 | 0.0886 | **4.18** |
| 2.5 | 0.0107 | 0.0903 | 0.0000 | 低于噪声 |

**`W2_corr/h` 近似常数（3.49 → 3.84 → 4.18，波动 ±9%）。** 这就是 Lipschitz 连续性的直接数值证据：W2 与参数距离成正比。

**（b）全网格 180 对相邻格点。** `W2/h` 最大 5.68、中位数 0.93、p95 5.12——**全部有限**。若不连续，沿趋近不连续点的路径会有 `W2/h → ∞`。

**（c）对照组。** 同一个初值云在两个格点间 `W2 = 0`（精确 0），确认管线在被比较对象相同时正确返回零。

### 5.2 数学证明：Lipschitz 连续

**定理.** 在核正则性 (A1)、漂移联合 Lipschitz (A2)、剪切项 Lipschitz (A3)、初值共享 (A4) 下，存在常数 `L`：

```
W2(ν_{θ₁}, ν_{θ₂}) ≤ L·(|σ₁−σ₂| + √|μ₁−μ₂|)
```

即对 σ 是 **Lipschitz 连续**，对 μ 是 **1/2 阶 Hölder 连续**。

**证明思路**：用同步布朗运动耦合两条 SDE，对 `E|X_t − Y_t|²` 用 Itô + Grönwall，得 `E|X_T − Y_T|² ≤ C_T(|Δσ|² + |Δμ|)`。同步耦合下 `W2² ≤ E|X_T − Y_T|²`，开方即得。μ 的 1/2 阶来自 `√(2μ)` 的平方根 Hölder 性。

完整证明（含假设的逐条验证）见 **`docs/CONTINUITY.md` §2**。

### 5.3 为什么 μ 方向更难观察

定理给出 μ 是 `√|Δμ|` 的界（比 σ 的线性界弱），加上扩散位移 `√(2μT) = 0.2` 相对云尺度 1.0 很小。实测 μ 的信号斜率 0.33，σ 是 3.60——**相差 11 倍**。μ 变化 25% 就淹没在 N=20k 的统计噪声里。

**这不影响 μ 作为网络输入的价值**：网络可以从 100k 个粒子的整体形状里提取 μ 的信息，而人眼/单个几何量做不到。

### 5.4 统计噪声的角色

经验测度的 W2 偏差满足 `E[W2²(μ^N, ν)] ≤ C·N^{-2/3}`（d=3，Fournier–Guillin 2015）。所以两团独立云的测得距离是

```
W2_meas² ≈ W2_signal² + W2_noise²
```

这解释了全部观测：参数差大时测得 ≈ 信号；参数差极小时测得 ≈ 噪声基底（实测 0.0931 ± 0.0020）。**连续性一直存在，只是小参数差时被噪声掩盖。**

## 7. 局限

1. **只跑了 MeanFlow 一步生成**，没做两步 MF 和 DP 精修。单参数的这些结果在 `results/ks3d/` 里。
2. **σ 方向只取 10 档**，而上游评测用 20 档（步长 10）。本实验的 σ 端点是 10 和 200，中间是对数间距——与上游训练网格一致，但比上游评测网格稀疏。
3. **20k 粒子**，而上游评测用 100k。噪声基底 0.093 对应 20k；用 100k 会降到约 0.067，但生成成本 ×5。
4. **μ 的灵敏度弱**（斜率 0.33 vs σ 的 3.60），所以 μ 方向的结论比 σ 方向更依赖噪声扣除。
5. **没有做 μ 的极端压力测试**（如 μ=100），那里可能出现数值不稳定。
6. **单参数对照模型的对比只在 72 个"双留出"格上**（排除 LHS 训练集和 μ=1 切片），样本量有限。
