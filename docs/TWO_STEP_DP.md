# 双参数 Two-Step Diffusion：MeanFlow + DP

> **结论：在双参数 (σ, μ) 上完成两步扩散（MF + DP），测试误差从 0.1228 降至 0.1043
> （−15.0%），141/143 格胜出，且提升在全部 μ 区间均匀（13.6%–18.4%）。**

---

## 1. 为什么必须补这个实验

此前双参数的主结果只报告了 **MeanFlow 一步生成**。但本工作研究的方法是**两步扩散**：

```
stage 1   MF   : x_mf = x − u_θ(x, r=0, t=1, log σ, log μ)      ← 冻结
stage 2   DP   : x_dp = x_mf + α · MLP(x_mf, log σ, log μ)       ← 修正器
```

**因此主结果必须包含 DP 阶段**，否则报告的不是所研究的方法。

---

## 2. 协议

### 2.1 网络

| 阶段 | 结构 | 参数量 |
|---|---|---|
| MF | 4 层 MLP，宽 64，3 隐层 SELU，7 输入 | 9,155 |
| **DP 修正器** | Linear(d+2→64) + 2×[LayerNorm → Linear(64,64) → SiLU → Linear(64,64)] + Linear(64,3) | 约 26 k |

DP 为**近恒等**结构：$x_{\text{out}} = x + \alpha\cdot\text{MLP}(x,c)$，输出层零初始化，故训练起点是恒等映射。

### 2.2 损失

$$\mathcal{L} = \underbrace{\|x_{\text{dp}} - x_{\text{matched}}\|^2}_{\text{传输}} + \lambda\underbrace{\|x_{\text{dp}} - x_{\text{mf}}\|^2}_{\text{残差}},\qquad \lambda=1$$

$x_{\text{matched}}$ 为用**精确 OT** 将目标云按当前预测重新匹配后的对应点。

### 2.3 关键实现细节：批次与匹配必须同步刷新

OT 返回的排列是**批次内位置**的索引。若批次每步重新抽取而匹配不重算，排列会指向错误的粒子。

因此本实现中**批次只在刷新匹配时重抽**：

```python
refresh = batch_idx is None or (step - 1) % ot_refresh == 0
if refresh:
    batch_idx = randperm(N)[:batch]      # 新批次
    perm = exact_OT(model(batch), target) # 匹配同一批次
```

（这是本仓库早期的一个真实 bug：批次与匹配不同步导致 loss 从 0.025 涨到 1.13、误差恶化 3.4 倍，且不报错。）

### 2.4 超参

| 项 | 值 |
|---|---|
| MF 权重 | `optimal_budget_ablation/two_32000`（每格 32,000 更新，已收敛）|
| DP 训练格点 | 同一 40 个 LHS 格 |
| DP 预算 | **每格 2,000 更新**（共 80,000 步）|
| batch | 2,000 |
| α | 1.0 |
| 残差权重 λ | 1.0 |
| OT 刷新间隔 | 10 步 |
| 优化器 | Adam，lr = 1e-4 |
| 训练耗时 | 约 2.6 小时 |

## 3. 结果（16 箱直方图 W2，143 个留出格）

| 阶段 | 平均 W2 | 相对噪声基底 | 胜出 |
|---|---:|---:|---:|
| MF 单独 | 0.12277 | 1.91× | — |
| **MF + DP** | **0.10429** | **1.62×** | **141/143** |

**相对改进 +15.0%**，中位增益 0.0180。

### 3.1 按 μ 距离分档

| $\lvert\log_{10}\mu\rvert$ | $n$ | MF | MF+DP | **改进** | 相对 |
|---:|---:|---:|---:|---:|---:|
| 0.20 | 32 | 0.11351 | 0.09627 | +0.01724 | **+15.2%** |
| 0.40 | 33 | 0.11938 | 0.10138 | +0.01800 | +15.1% |
| 0.60 | 32 | 0.12769 | 0.10799 | +0.01970 | +15.4% |
| 0.80 | 16 | 0.08189 | 0.06679 | +0.01510 | **+18.4%** |
| **1.00（$\mu{=}10$）** | 30 | 0.15292 | 0.13210 | +0.02081 | +13.6% |

**提升在 13.6%–18.4% 之间，几乎不依赖 $\mu$**（$\mathrm{corr}=0.115$）。

这与「DP 是通用的近恒等修正器，其收益主要来自修正 $\sigma$ 方向的结构误差」一致——不像 MF 的参数耦合能力那样集中在某个区域。

## 4. 预算的作用

| DP 预算/格 | 总步数 | MF+DP W2 | 改进 | 胜出 |
|---:|---:|---:|---:|---:|
| 50 | 2,000 | 0.11258 | +8.3% | 125/143 |
| **2,000** | **80,000** | **0.10429** | **+15.0%** | **141/143** |

**预算增 40 倍，改善接近翻倍**（8.3% → 15.0%），说明 DP 尚未饱和。

## 6. 推理成本

| 阶段 | 前向次数 | 延迟（100k 粒子，本机）|
|---|---:|---:|
| MF 一步 | 1 | 约 4.5 ms |
| **MF + DP** | **2** | 约 7.7 ms |

**DP 使推理成本增至 1.71 倍。** 若严格要求单次前向，只能用 MF 一步（误差 0.1228）。

**这是个必须明说的权衡**：两步扩散的两个阶段带来精度提升，但也带来一次额外前向。论文应同时报告两个数字，并说明取舍。

---

## 7. 局限

1. **单种子**。DP 与 MF 的对比各只有 seed 88。虽然 141/143 格的胜率很高，但严格置信区间需多种子。
2. **DP 未饱和**。2,000 更新/格仍是 15% 提升，继续加预算可能更好。
3. **未做超参扫描**。α、λ、OT 刷新间隔、学习率都取单组值。
4. **只报直方图口径**。粒子级口径下 DP 的收益未测（按此前经验，粒子级会给出略小的相对幅度）。
